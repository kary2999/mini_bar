Minbar v1.3.0 · 2026.04 · macOS 11+ Apple Silicon
🎯 开发目的
工作间隙偷得浮生半日闲。常驻菜单栏的小浮窗浏览器。
支持多 Tab、多窗口、独立代理 — 一个窗口走 VPN 看 GitHub，
另一个窗口直连看 B 站，互不干扰。
数据本地存储，与 Safari 完全隔离。
📂 数据存储（独立目录）
~/.minbar/config.json  // 用户配置
~/.minbar-data/history.json  // 7d 自动清理
~/.minbar-data/webdata/{w1,w2,...}/  // 每窗口独立 Cookie/Cache
