为什么换样子？
旧菜单是系统默认 NSMenu — 单调、无层次、没有可视化控件。
新版用 NSPopover 自定义面板，把高频操作放快捷格，状态信息（代理 / 模式 / 窗口数）一眼可见。
✓ Header 显示当前 Boss
头像 + 名字 + 模式 + 窗口数，让你知道"现在在哪个工作区"
✓ 4 个 Quick Action
显示/隐藏 · 新窗口 · 整理 · 首页 — 高频操作一键直达
✓ 摆放 = 方向键盘 + 样式切换
3×3 网格直接点方向，平铺/叠放分段控件，像系统设置
✓ 滑块直接调透明度 / 间距
不再钻三层菜单选 80% — 现场拖滑块
✓ 代理 / 置顶 / 无痕 行内切换
状态徽章 + Toggle，无需进对话框
✓ 彩色图标 + 圆角 + 留白
视觉层次清晰 · 跟随系统明暗模式
